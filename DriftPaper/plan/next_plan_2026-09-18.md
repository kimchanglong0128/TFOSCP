## 0. 文献检索后的定位（先读这一节）

**坑位仍然是空的**：截至 2026-09-18 没有论文做到「严格 1 NFE + 免训练 + 参考图身份」。但三件事改变了写法：

1. **MoNO（2607.23937，2026-07，已核原文）** 与我们的几何对象几乎相同：同 ρ=0.15 圆形 FFT 低通、同「高频冻结 + 低频保范」的仿射球面、同测地线旋转更新（默认转角 20°/30°），在 SDXL-Turbo 与 DMD2 单步上测。差别：目标是多样性（DINOv2 子空间正交、无参考锚），方式是每样本 2–5 次前向的迭代优化。**结论：「保范低频旋转」这个手法本身不再是贡献。** 我们的贡献必须落在：(i) 单步身份坍塌的 query 侧诊断（K/V 全阴性 + 起点侧全阳性 + 两遍法 + 狗锚）；(ii) 闭式、一次、朝参考方向的旋转目标（1 NFE，无梯度）；(iii) 身份这个应用；(iv) 命题 1 给出 MoNO 没有的 pushforward KL 代价。summary 已引 MoNO 并写「沿用其球面约束、换目标」，方向对，但要放进 method 正文正面比较，不能只在脚注。
2. **Colorful-Noise（2605.00548，SIGGRAPH 2026）** 免训练地把初始噪声低频带换成参考图的，用于颜色与粗结构控制，不处理范数与高斯性。**LENS（2605.07253）** 用轻量网络只调噪声低频子空间，有 Prop 3.1 界住「只倾斜低频」的 KL 代价。两篇都证明「布局住在 ε 低频」已是共识（约束 3 不再需要我们证明），也都要引。
3. **SwiftPie（2605.01510）** 是唯一 1 步 + DMD2 + IP-Adapter 的实证，但需训练；其观察「多步目标不迁移 + 模态竞争」和修法「mask⊙Attn(image) 输出门控」独立佐证了我们「1 步下有效的是空间门控不是 K/V 缩放」。**FastFace（2505.21144）** 只做 4 步且操作的是 softmax 后的注意力图（query 依赖）。**PuLID** 报告 Lightning 4 步下 IP-Adapter 身份反而更高，是反证，要用「4 步不掉、1 步崩」调和。**OPAD** 的解释（分布匹配丢弃逐轨迹映射）预测 DMD2 应比 LCM 差，与我们数据相反，可直接检验。

**「保范 ⇒ 先验密度保持」不够用。** 这是逐点陈述；旋转后的 pushforward 距先验测度的 KL ≈ −(d_L−2)·log cos θ，d_L≈1200、θ=45° 时约 400 nats。要写成「受控信息预算」，并报告 ε′ 的成对相关与 patch 矩（ReNoise 判据）。见 §5 命题 1。

**t_start 分析是文献空白**（无人做过 999/800/399 消融），值得作独立贡献；Hyper-SD 官方给了动机（「更小时间步输入提升单步预测可信度」，故 1 步用 t=800 全 UNet）。

### 卡 B1 · 消融：增益来自身份还是构图（优先级 1，决定主张 C 怎么写）

**目标** 分离「身份信息经低频进入」与「构图先验」。
**协议** 同 ρ=0.15、θ=45°、DMD2 + FaceID、30×20，只换源图：
- A 现方法：参考脸对齐平均脸框 + 涂灰冲突区 + prompt 背景 → VAE。
- B 平均脸：30 身份像素均值脸替换参考脸，其余同。
- C 椭圆剪影：脸框内灰色椭圆，无五官。
- D 他人脸：另一身份对齐到同一脸框（狗锚的人脸版）。
**判定** ArcFace(A)−ArcFace(B) 配对 p<0.05 且 ≥+0.015 → 身份经低频进入；否则主张 C 改写为「构图先验修复单步身份定位」。D≈A 进一步说明身份不经低频进入。
**正确性检查** θ=0 四组逐像素=基线；报告 B/C/D 的 z_L 与 A 的 z_L 余弦。
**算力** 2400 张 + 评测，A100 约 40 分钟。
**代码** `build_source(reference, prompt, mode∈{ref, meanface, silhouette, other_id})`；旋转与评测不动。
**结果** (a) 2026-09-21：DINO 0.670→0.710（+0.040，p=3e-7，27/30），held-out DINO +0.031（p=1e-4），CLIP-I +0.021；**CLIP-T 0.282→0.265（−0.018，p=6e-12，28/30 下降）**→ 按判定规则不通过：整幅参考图作源会把参考场景一并转入噪声（复制构图）。物体/宠物同向。θ=0 对照 30/30 逐像素 = 基线。详见 exp/LOG.md 第八轮。(b) 抠主体+粗对齐+无参考场景背景：DINO +0.033（p=3e-5，28/30），held-out +0.029（p=4e-4），CLIP-T −0.010（p=1e-6，27/30 下降）→ 不通过但代价减半；(c) 中心椭圆：DINO +0.007（p=0.23）无效，CLIP-T −0.004。**按判定规则：标题限 identity，通用主体入 discussion**；未扫预算，CLIP-T 不降的工作点未排除。

### 卡 D2 · 区分两种解释：query 缺结构 vs OPAD 的轨迹映射丢失（优先级 5）

## 4. 论文定位修订（文献后）

**一句话**：单步蒸馏生成器上，参考图身份经 IP-Adapter 注入后丢失的瓶颈不在注入内容而在 query 缺乏空间结构；只需对初始噪声的低频做一次朝参考方向的保范旋转（1 NFE、免训练），DMD2 上恢复并超过 4 步基线。

**四条主张与文献关系**
- A 现象（生成器+适配器特异，非单步本身）：与 PuLID 反证调和（4 步不掉、1 步崩）；引 When Few Steps 的 1 步 0.015。

## 5. 可证的两个命题（理论章节，详见 lit_4 §c）
